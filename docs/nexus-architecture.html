📓 Project Journal — Cross-Session State Tracking

Tool-agnostic tracking that works with Coding Agent, Claude Code, Cursor, and any future AI agent

🔄
Auto-Rolling Sessions
On Every journal log
Stale session (idle ≥4h, new UTC date, branch changed) auto-closes and a new one opens — no manual session-start/end
🔨
post-commit Hook
On Every git commit
Auto-logs commit subject; auto-rolls if stale; regenerates state-summary.md + state-dashboard.html on every commit
🚀
pre-push Hook
On Every git push
Regenerates state-dashboard.html + state-summary.md before code leaves your machine
🩺
Drift Detection
On nexus init --upgrade
journal health flags missing/stale/drift; refresh backfills any commits not yet captured by the journal
1
One-time setup per project
nexus init creates the canonical AGENTS.md block, project skills, native adapters, install manifest, and initial state-summary.md
2
State auto-tracked across files
Every commit triggers post-commit hook → journal log → auto-roll (if stale) → daily archive append → state.md (CC-grouped) → state-summary.md (AI-optimized) → state-dashboard.html (git-derived heatmap)
3
Any AI agent reads state on entry
AGENTS.md is the shared entry point for Codex, Devin, Cursor, and Copilot/VS Code. CLAUDE.md imports it, while .agents/skills and the synchronized .claude/skills projection provide just-in-time workflows.
Cross-tool surface
4
Drift detection on upgrade
nexus init --upgrade runs journal health: detects commits missing from done, stale state, or PRD newer than last journal update. Auto-refresh backfills missing commits into done + daily archive (tagged [backfill])
Self-healing
5
Decisions captured as ADRs
journal decision add "<title>" writes a MADR-minimal stub at docs/decisions/NNNN-slug.md (committed by default, not under .nexus/) and auto-logs the creation
🤖 .nexus/state-summary.md
Four-field snapshot (at most 80 lines): Intent, Changes Made, Decisions Taken, Next Steps / Blockers. Read this first.
📄 .nexus/state.md
Full journal grouped by Conventional Commits type (Features / Fixes / Refactoring / Docs / ...). Branch tag on every entry.
⚙️ .nexus/state.json
Machine-readable rolling buffer (last 100 done entries). Source of truth for dashboards; daily archive is the permanent record.
🗓️ .nexus/journal/YYYY-MM/DD.md
Append-only daily archive — the system of record. Survives state.json corruption, branch resets, and the rolling-buffer trim.
📊 state-dashboard.html
Self-contained dark-mode HTML. Status cards, session timeline, git-derived heatmap, recent commits, audit trail. No server needed.
📜 docs/decisions/NNNN-slug.md
MADR-minimal architectural decision records. Committed by default (not under .nexus/), so they travel with the code in version control.
