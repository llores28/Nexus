# Nexus Universal Project Enhancement

This optional prompt enriches an already installed Nexus project. It does not replace `nexus init`.

## Canonical surfaces

- `AGENTS.md`: stable shared instructions
- Scoped `AGENTS.md`: subtree-only differences
- `.agents/skills/<name>/SKILL.md`: reusable provider-neutral workflows
- `.nexus/profile.json`: generator configuration

Provider adapters contain only provider-specific deltas. Claude's `.claude/skills` directory is generated by Nexus from canonical skills.

## Procedure

1. Search repository evidence and build a bounded component/command map.
2. Select Fast, Team, or Enterprise depth based on risk and collaboration needs.
3. Add only stable shared rules and repeatable skills supported by evidence.
4. Preserve user content, managed-file boundaries, and legacy migration inputs.
5. Run `nexus generate`, verified project tests, `nexus doctor --consumer all --deep`, `nexus context audit`, and the secrets scan.

Never invent commands, duplicate shared rules, create obsolete instruction surfaces, or claim a clean result while warnings remain.
